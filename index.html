ℹ️ How to play

Choose a game and follow the prompt. Correct answers earn XP. Questions are shuffled and remembered locally so they don't repeat until the current pool has been used up. Change difficulty in Settings.

In Music Corner, choose an instrument and tap notes or play a tune. Sound starts after a tap because browsers require user interaction before audio playback.

Offline note: the game itself uses no external libraries or audio files. It can keep working while this page stays open offline. To reliably reopen the site offline after closing it, GitHub Pages needs a separate service-worker file; a single HTML file alone cannot install a service worker.

For your NFC card, keep the same website URL written as a URL/URI record. Updating this file won't require rewriting the card.
